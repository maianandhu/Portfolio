## 💻 Technical Stack (Portfolio Build)
This website is a static single-page application (SPA) built entirely without frameworks.
* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom animations (Bat-pulse, rainbow transitions, glitches), CSS variables for theme management, and responsive grid layouts.
* **Vanilla JavaScript (ES6+):** Interactive logic, DOM manipulation, and audio streaming.

---

## ⚙️ Unique System Features
* **Batcave Radio:** A fully functional, custom-built MP3 player with array-based track loading, progress seeking, and volume control.
* **Interactive Terminal:** A functioning command-line interface. Try typing `help`, `projects`, or `bat`!
* **Data-Cleaning Mini-Game:** A custom HTML5 `<canvas>` game utilizing 2D collision detection and gameloop intervals.
* **Dynamic Cursor & Bat-Trail:** Custom JavaScript math (Pythagorean theorem for distance calculation) to track mouse velocity and render a fading bat-trail.
